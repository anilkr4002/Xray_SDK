# X-Ray Debugger

A lightweight X-Ray system for debugging non-deterministic, multi-step decision pipelines.

## What It Solves
Traditional logs show *what* happened.
X-Ray shows *why* a decision was made.

## Features
- Execution-level decision tracing
- Step-by-step reasoning capture
- Filter-level pass/fail explanations
- Ranking transparency

## Tech Stack
- React + Vite
- Tailwind CSS
- Custom X-Ray SDK (framework-agnostic)

## Run Locally
```bash
npm install
npm run dev
